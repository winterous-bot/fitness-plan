塑形训练助手 V1.0 - 安卓 PWA

1. 在 GitHub 新建公开仓库，例如 fitness-plan。
2. 将 ZIP 解压后的 index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png 上传到仓库根目录。
3. Settings → Pages → Deploy from a branch → main / (root)。
4. 在安卓 Chrome 浏览器打开发布后的 HTTPS 网页，选择菜单中的「安装应用」或「添加到主屏幕」。不同品牌系统操作入口可能不同。
5. App 数据存在当前设备当前浏览器的 localStorage 内，不能跨设备自动同步。定期在「设置 → 导出完整备份」保留 JSON 文件。
6. 「导入备份」将覆盖当前全部数据。更新网页代码不应清空本地数据，但清除网站数据、重装应用或更换浏览器可能导致数据丢失。

功能：4套力量训练模板在3个力量训练日轮换；独立有氧；每组重量/次数/完成勾选；逐项动作打卡；计划/动作编辑；训练历史编辑；体重目标和趋势；完整JSON备份；PWA离线缓存。
说明：不具备后台消息推送或云端同步。

V1.3 新增：历史页最近28天完成率、近四周训练次数、动作 PR；身体页最近90天体重趋势。
数据兼容 V1.0-V1.2：仍使用原 localStorage 键 fitness-tracker-v1，不迁移、不覆盖。更新前务必导出 JSON 备份。
统计说明：计划完成率按当前每周排期推算；PR 仅采集已勾选完成且有有效重量和次数的组；趋势图只使用已录入数据。
